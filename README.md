# Mahmoud Moselhy — Portfolio starter

## Files
- `index.html` — page content
- `styles.css` — responsive dark theme
- `script.js` — mobile navigation and footer year
- `assets/` — put your CV PDF here as `Mahmoud_Moselhy_CV.pdf`

## Before publishing
1. Replace the LinkedIn placeholder URLs in `index.html` with your actual profile URL.
2. Add your CV PDF to `assets/Mahmoud_Moselhy_CV.pdf`.
3. Replace the generic project repository links with exact repository URLs.
4. Review every experience, project, and skill statement for accuracy.
5. Test locally by opening `index.html` in a browser.

## Publish with GitHub Pages
From the repository folder:
```powershell
git add .
git commit -m "Build personal portfolio website"
git push origin main
```
Then enable GitHub Pages in Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

The intended site URL is `https://mahmoudmoselhy.github.io/`.
